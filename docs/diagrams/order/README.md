# Order

Diagramas recomendados:

- `flow-order-creation.md`: cliente, lineas, precios, descuentos y confirmacion.
- `sequence-order-confirmation.md`: confirmacion completa entre frontend y backend.
- `flow-confirmation-transaction.md`: validaciones, stock, venta, pago y auditoria.
- `flow-confirmation-idempotency.md`: doble click, reintento y deduplicacion.
- `state-order-lifecycle.md`: `CONFIRMED`, `DELIVERED` y `CANCELLED`.
- `flow-edit-confirmed-order.md`: modificacion administrativa y delta de stock.
- `flow-cancel-order.md`: reglas para cancelar una venta no pagada.
- `er-order.md`: pedido, items, snapshots, venta y cliente.
